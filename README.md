# 🎵 Sistema Musical

Projeto de desenvolvimento web para gerenciamento de uma biblioteca musical. O sistema permite organizar artistas, cadastrar músicas e visualizar uma biblioteca musical por meio de uma interface simples e intuitiva.

## 📌 Funcionalidades

- **Login:** tela de entrada com campos de usuário e senha.
- **Menu principal:** acesso às principais funcionalidades do sistema.
- **Cadastro de artistas:** permite cadastrar nome, gênero musical, país e foto do artista.
- **Cadastro de músicas:** permite adicionar título, artista, álbum, gênero, link do YouTube, capa e letra da música.
- **Biblioteca musical:** exibe as músicas cadastradas em uma tabela.
- **Filtros:** opções para pesquisar músicas por título, álbum, artista e gênero.
- **Design responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 🗂️ Estrutura dos arquivos

```text
projeto/
```

## 🛠️ Tecnologias utilizadas

- **HTML5:** utilizado para estruturar as páginas, formulários, tabelas e menus.
- **CSS3:** utilizado para estilizar as páginas, definir cores, organizar elementos e criar um layout responsivo.

## ▶️ Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se todos os arquivos estão na mesma pasta.
4. Abra o arquivo `login.html` ou `index.html` no navegador.
5. Também é possível utilizar a extensão Live Server do VS Code para executar o projeto.

## 🎨 Identidade visual

O sistema utiliza uma identidade visual baseada em tons de azul, verde, vermelho e branco.

O arquivo `style.css` concentra toda a estilização do projeto, incluindo:

- Formulários e campos de entrada.
- Botões e links.
- Tabelas de dados.
- Cabeçalhos e menus.
- Cartões e filtros.
- Adaptação para dispositivos móveis.

## ⚙️ Estado atual do projeto

Atualmente, o projeto possui a estrutura visual desenvolvida em HTML e CSS. Os dados apresentados nas tabelas são exemplos fixos, e os formulários ainda não possuem integração com banco de dados.

As funcionalidades de autenticação, cadastro, edição, exclusão e filtragem dinâmica poderão ser implementadas posteriormente com uma linguagem de programação back-end e um banco de dados.
